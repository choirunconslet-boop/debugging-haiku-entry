Haiku about debugging for the make.fun bounty **"Seventeen Syllables of Debugging"**.

`main.py` writes one haiku — three lines in the 5-7-5 syllable shape — to `/output/entry.txt`:

> Cursor blinks at three
> one log line lies, so certain
> the bug was all mine

Syllable count: 5 + 7 + 5 = 17.
